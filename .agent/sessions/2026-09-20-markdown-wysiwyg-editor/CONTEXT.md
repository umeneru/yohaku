# Markdown Editing

Yohaku. におけるMarkdown文書と、その編集体験を表す用語を定義する。

## Language

**Markdown文書**:
Markdownテキストを正本として保存し、整形された状態で編集する文書。対象拡張子は`.md`と`.markdown`。
_Avoid_: リッチテキストファイル、HTML文書

**リッチ編集**:
Markdown記号を通常は表示せず、見出し・強調・リストなどの意味と見た目を直接操作する編集体験。
_Avoid_: プレビュー、ソース編集、完全WYSIWYG

**プレーンテキスト文書**:
Markdown文書以外の、文字列をそのまま表示・編集する文書。
_Avoid_: Markdown文書

**対応Markdown**:
基本Markdownに、取り消し線・タスクリスト・表を加えた文書表現の範囲。
_Avoid_: 独自Markdown、独自記法

**表記正規化**:
文書の意味を維持したまま、同義のMarkdown記法や空白などを統一すること。
_Avoid_: 内容変更、完全往復

**画像資産**:
Markdown文書へ貼り付けられ、文書から相対参照されるPNG画像ファイル。
_Avoid_: 添付ファイル、埋め込み画像

**画像資産ディレクトリ**:
同じディレクトリにあるMarkdown文書が画像資産を共有する`assets/`ディレクトリ。
_Avoid_: 文書専用画像ディレクトリ、添付フォルダ

**安全フォールバック**:
対応外Markdownの損失を避けるため、文書全体をプレーンテキストとして編集する状態。
_Avoid_: 部分的な生表示、強制変換
